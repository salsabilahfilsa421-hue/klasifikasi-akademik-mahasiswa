# klasifikasi-akademik-mahasiswa
Penerapan Machine Learning untuk klasifikasi status akademik mahasiswa (Lulus/Tidak Lulus) berdasarkan kehadiran, partisipasi diskusi, dan aktivitas E-Learning dengan membandingkan Logistic Regression, Decision Tree, dan Random Forest. Proyek ini mendukung SDGs 4 – Quality Education melalui pemanfaatan teknologi dan analisis data.
